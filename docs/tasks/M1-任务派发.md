**骨架示例（`board.py`，可直接抄着改）**

```python
"""棋盘数据模型：一维 100 格，索引 = r * 10 + c。"""

BOARD_SIZE = 10
CELL_COUNT = BOARD_SIZE * BOARD_SIZE

EMPTY = 0
BLACK = 1
WHITE = 2
ARROW = 3

Board = list[int]


def idx(r: int, c: int) -> int:
    return r * BOARD_SIZE + c


def rc(i: int) -> tuple[int, int]:
    return divmod(i, BOARD_SIZE)


def in_bounds(r: int, c: int) -> bool:
    return 0 <= r < BOARD_SIZE and 0 <= c < BOARD_SIZE


def at(board: Board, r: int, c: int) -> int:
    """越界返回 -1。"""
    if not in_bounds(r, c):
        return -1
    return board[idx(r, c)]


def clone(board: Board) -> Board:
    return board[:]


def initial_board() -> Board:
    board = [EMPTY] * CELL_COUNT
    for r, c in [(0, 3), (3, 0), (6, 9), (9, 6)]:
        board[idx(r, c)] = BLACK
    for r, c in [(0, 6), (3, 9), (6, 0), (9, 3)]:
        board[idx(r, c)] = WHITE
    return board
```

**规则要点（读懂代码时对着这几条检查）**

1. 一步棋 = **先移动一个己方亚马逊，再从落点射一支箭**，两段都走**皇后路线**（8 个方向横竖斜任意距离），路径上不能有棋子或箭头。
2. 箭从棋子**落点**出发；箭不能射到自己所在格（该格已被自己占住）。
3. 棋子和箭头占的格子：不可通过、不可落子；箭头永不消失。
4. 该方没有任何合法走法 → 该方判负；双方都走不动 → 和棋。
5. 题目册只规定“行棋方法与皇后相同”，**没有马步 / 骑士走法**，别自作主张加进去。

**要做的事**

1. 实现 `evaluate(board, color) -> int`：**正数表示对 `color` 有利，负数不利**
2. 至少 3 个特征，先写最朴素的版本就行：机动性（可走格数）、领地（可活动格数）、棋子位置权值
3. 必须有一条测试：`evaluate(board, WHITE) == -evaluate(board, BLACK)`（零和一致性）
4. 函数必须是纯函数：**不允许修改传入的 `board`**

**骨架示例（`ai_eval.py`）**

```python
"""局面估值：正数表示对 color 有利。"""

from board import BLACK, BOARD_SIZE, WHITE
from rule import piece_targets, territory

DEFAULT_WEIGHTS = {"mobility": 1.0, "territory": 0.5}


def _other(color: int) -> int:
    return BLACK if color == WHITE else WHITE


def _mobility(board, color: int) -> int:
    total = 0
    for i, v in enumerate(board):
        if v == color:
            r, c = divmod(i, BOARD_SIZE)
            total += len(piece_targets(board, r, c))
    return total


def evaluate(board, color: int) -> int:
    black_t, white_t = territory(board)
    my_t, opp_t = (white_t, black_t) if color == WHITE else (black_t, white_t)
    score = DEFAULT_WEIGHTS["mobility"] * (_mobility(board, color) - _mobility(board, _opp))
    return int(score)
```
