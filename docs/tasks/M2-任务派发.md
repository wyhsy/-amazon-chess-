## 1. @guoyi1005 —— 界面交互

| 项目 | 内容 |
| --- | --- |
| 只能改 | `ui.py`、`assets/` |
| 分支名 | `feature/ui-interaction` |
| 可用接口 | `rule.piece_targets / shot_targets / apply_move / game_result`；`ai_search.search_by_difficulty` |
| 禁止 | import `ai_eval`；改 `board.py` / `rule.py` |

**要做的事**

1. **两段式状态机**（核心）
   - `self.selected`：当前选中的己方棋子 `(r, c)`
   - `self.pending_move`：已选好落点、等待射箭 `(src, dst)`
   - 点击顺序：己方棋子 → 合法落点 → 合法箭位 → `apply_move` 落子、切换 `self.turn`、清空两个字段
   - 再点一次已选中的棋子 = 取消选中；点空白/非法格 = 清空重来
2. **非法操作提示**（不能崩）：点到对方棋子、箭头、路径被挡、箭射到自己落点等，写 `self.message`（例如“这里走不过去”），不要抛异常
3. **走法提示（可选但推荐）**：选中棋子后用半透明格标出 `piece_targets`；选好落点后标出 `shot_targets`
4. **终局与重开**：每步落子后用 `rule.game_result(self.board)` 判断；显示“白方获胜 / 黑方获胜 / 和棋”；提供“再来一局”（重置 `board / turn / selected / pending_move / message`）
5. **pve 接线**
   - 人类走完后，如果 `self.mode == "pve"` 且 `self.turn != self.human_color`，调用
     `ai_search.search_by_difficulty(self.board, self.turn, self.difficulty)`
   - 调用前把状态栏设为“AI 思考中…”，先 `pygame.display.flip()` 刷新一次再搜索；搜索返回后 `apply_move` 并切回人类
   - M2 允许在 UI 线程同步搜索（≤3 秒）；M4 再考虑放线程里

**验收标准**

- [ ] `python ui.py` 能下完一局 pvp：每步都要经过“选棋子 → 选落点 → 选箭位”
- [ ] 非法点击有提示、不崩溃
- [ ] 胜负/和棋提示正确，“再来一局”能重置
- [ ] `python -c "import ui"` 无报错；没有 import `ai_eval`
- [ ] `python -m pytest -q` 仍全绿
